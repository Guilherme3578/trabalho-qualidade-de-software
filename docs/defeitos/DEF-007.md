## Passos para reproduzir

1. Abrir um PR e deixar o CI rodar `./mvnw verify`.

## Resultado esperado

Testes de integração rodam contra o banco do Testcontainers.

## Resultado obtido

Todos falhavam com `MongoDBContainer should be started first`; depois, o MongoDB sem replica set recusava transações.

## Causa

O bean `@ServiceConnection` condicional era criado sem iniciar o container; no Testcontainers 2.x o MongoDB deixou de subir como replica set por padrão.

## Correção

Container iniciado explicitamente em `ContainersTeste` e URL passada por `@DynamicPropertySource`; replica set ativado.

## Verificação

Teste(s): Toda a suíte de integração no CI do PR #1. Passam na suíte atual (`./mvnw verify` e CI da `main`).

**Observação:** Defeito da época do MongoDB. Depois da migração para MySQL (PR #3) o mesmo padrão (container iniciado antes do contexto) foi mantido em `ContainersTeste` com `mysql:8.4`.
