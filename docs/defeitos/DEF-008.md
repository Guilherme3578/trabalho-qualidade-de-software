## Passos para reproduzir

1. `./mvnw spring-boot:run` (ou o `.jar`, ou a imagem Docker).
2. Abrir `http://localhost:8080`.

## Resultado esperado

Interface Angular.

## Resultado obtido

Front antigo em HTML/JS de `src/main/resources/static/`. Nos computadores da sala (Node 22.11), o `npm start` do Angular nem roda.

## Causa

O Angular era executado à parte (porta 4200) e não entrava no `.jar`. Defeito latente encontrado na correção: o build de produção do Angular carrega o CSS com `onload` inline, bloqueado pela CSP.

## Correção

`frontend-maven-plugin` com Node 22.22.1 próprio compila o Angular no build e o copia para `static/`; `FrontendConfig` encaminha as rotas para o `index.html`; `inlineCritical` desligado; front antigo removido.

## Verificação

Teste(s): `FluxoReservaE2EIT` (Selenium sobre o Angular servido pelo Spring, incluindo estilos com CSP e layout em 390 px), `SegurancaApiIT` (rotas do front sem token). Passam na suíte atual (`./mvnw verify` e CI da `main`).
